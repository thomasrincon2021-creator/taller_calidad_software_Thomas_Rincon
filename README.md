# Taller de Calidad de Software - Backend (Frutas y Verduras)

## 📌 Descripción del Proyecto
Backend desarrollado en **Spring Boot** para la gestión y control de una tienda de frutas y verduras. El sistema permite administrar productos, inventario y autenticación de usuarios bajo los estándares de calidad de software requeridos.

## 🛠️ Tecnologías Utilizadas
* **Java** 
* **Spring Boot** 
* **Spring Data JPA** 
* **Gradle** 
* **MySQL** 
* **Git & GitHub**
