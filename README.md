# 🛒 Taller de Calidad de Software - Backend (Frutas y Verduras)

## 📌 Descripción del Proyecto
Backend robusto desarrollado en **Spring Boot** diseñado para la gestión integral de una tienda de frutas y verduras. El sistema implementa buenas prácticas de desarrollo y estándares de calidad de software, permitiendo la administración eficiente de productos, control de inventario y un sistema seguro de autenticación de usuarios.

---

## 🛠️ Tecnologías Utilizadas
* **Java** (Lenguaje de programación principal)
* **Spring Boot** (Framework para la creación de servicios REST)
* **Spring Data JPA** (Manejo de persistencia y conexión a base de datos)
* **Gradle** (Gestor de dependencias y automatización de compilación)
* **MySQL** (Base de datos relacional para el almacenamiento de la información)
* **GitHub** (Plataforma de colaboración y control de versiones)

---

## ⚙️ Arquitectura y Estructura del Proyecto
El proyecto está estructurado bajo el patrón arquitectónico Modelo-Vista-Controlador (MVC) y arquitectura en capas para asegurar la escalabilidad y el mantenimiento del código:
* **`controlador/`**: Endpoints REST para la comunicación con el cliente.
* **`repositorio/`**: Interfaces de comunicación directa con la base de datos (Spring Data JPA).
* **`modelo/`**: Entidades y mapeo de las tablas de la base de datos (Usuarios, Frutas, Verduras, etc.).
